# Health Log

Append-only narrative log of injuries, illnesses, and niggles. The structured equivalent lives in the `health_events` table — this file holds the prose: mechanism, what helped, what didn't, lessons learned.

The biweekly health-log audit recipe asks Claude to update entries here when events resolve.

## Format convention

Each event uses this block:

```
## YYYY-MM-DD — <body part or system> — <kind: injury|illness|symptom>

**Mechanism / onset:** <what happened, what you felt>
**Severity at onset:** <1-5, 5 = most severe>
**Treatment:** <what you tried, in chronological order>
**Resolution:** <date and outcome — leave blank while active>
**Lessons:** <what you'd do differently next time>
```
