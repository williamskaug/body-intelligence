# Personal records

Your achieved bests — distinct from `capacity_metrics`, which holds the
wearable's continuously-moving *predictions*. Maintained by the capacity-sync
recipe (from get_personal_record) and by you. One block per record, using the
exact shape below so it stays scannable and parseable.

## PR format convention

Each record uses this exact block:

```
## PR: <discipline/distance>
- Value: <time | distance | weight>
- Date: YYYY-MM-DD
- Where: <race/session — optional>
```
